# NodeMcuMqqt

Шаблон прошивки для NodeMCU: периодически снимает показания датчика BME280, публикует их
в MQTT и засыпает в `deepSleep` между циклами. Динамическое подключение к WiFi и поиск
MQTT-брокера в локальной сети, без ручной настройки при каждой прошивке.

## Железо

- Плата: NodeMCU v2 (ESP8266)
- Датчик: BME280 по I2C, адрес `0x76`
  - `SDA` → `D2 (GPIO4)`
  - `SCL` → `D1 (GPIO5)`
  - `VIN` → `3V3`
- Светодиод на `D4 (GPIO2)`, активный низ: горит во время сна, гаснет на время работы

## Как это работает

1. `setup()` поднимает WiFi через WiFiManager. Если сохранённой сети нет или подключиться
   не удалось, поднимается точка доступа **MQTTDevice** / **password** — заходишь с телефона
   и вводишь имя/пароль домашней сети.
2. Плата ищет MQTT-брокера в локалке: сначала пробует сохранённый в EEPROM адрес, иначе
   перебирает последний октет адреса от 1 до 255 на порту `1883`.
3. Найденный адрес кладётся в EEPROM, чтобы не сканировать сеть при каждом старте.
4. Задача отчёта читает BME280, собирает JSON и публикует его в топик `<MAC>/<Датчик>`.
5. `loop()` уходит в `ESP.deepSleep`, плата просыпается RTC-таймером, перезагружается и
   выполняет `setup()` заново. Глобальные переменные при этом **не сохраняются**, поэтому
   одна задача в `loop()` успевает выполниться ровно один раз.

Имя устройства — MAC-адрес WiFi без двоеточий, например `A0B1C2D3E4F5`.

## MQTT

Топик: `A0B1C2D3E4F5/BME280`

Payload:

```json
{"tempC":21.35,"humidity":48.12,"pressure":760.41}
```

- `tempC` — температура, °C
- `humidity` — влажность, %
- `pressure` — давление, мм рт. ст.

Брокер должен быть в той же подсети, что и плата, и принимать подключения без TLS и без
аутентификации. Порт `1883` и клиент `connect` в коде заданы константами
(`MqttConnector.h`), зашифрованного брокера этот шаблон не поддерживает.

## Сборка и прошивка

```powershell
pio run            # сборка
pio run -t upload  # прошивка
```

Всё через PlatformIO, окружение `nodemcuv2` в `platformio.ini`. Порт загрузки (`COM4`) и
скорость (`921600`) заданы там же — правь под свою машину.

Логи идут в Serial на 9600 бод:

```powershell
pio device monitor
```

При каждом цикле в лог падает найденный MQTT-адрес и собранный JSON. Если адрес `0.0.0.0` —
брокер не найден, проверь, что он в сети и слушает `1883`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `src/main.cpp` | `setup()` / `loop()`, задачи, сон |
| `include/WifiAutoConnector.h` | WiFi + AP-fallback, имя устройства из MAC |
| `include/MqttConnector.h` | поиск брокера, кэш IP в EEPROM, публикация |
| `include/BMEReader.h` | чтение BME280, перевод давления в мм рт. ст. |
| `include/TaskRunner.h` | очередь задач, общий интервал = НОД всех интервалов |
| `lib/` | вендоренные библиотеки, новые зависимости тянуть не нужно |
